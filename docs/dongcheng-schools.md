## 用于购房地图时的建议字段

后续如果将这份数据导入学区房地图，可以为每所学校补充：

- `district`：东城区
- `school_district`：所属学区
- `school_name`：学校名称
- `school_stage`：小学 / 初高中
- `tier`：图片标注的学区梯队
- `school_type`：老牌牛小 / 传统优质校 / 直升校 / 定向派位 / 普通校
- `address`：学校地址
- `latitude` / `longitude`：地图坐标
- `education_group`：教育集团或一体化关系
- `admission_note`：当年招生、派位或直升规则
- `source_year`：政策或资料年份
- `source_url`：官方来源链接

这样后续可以直接把重点学校作为地图锚点，而不必把所有学区边界都画出来。
