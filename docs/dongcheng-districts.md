# 北京东城区 8 个学区边界整理

> 本文档由“京选地图”中已经确认的边界整理而成。道路边界坐标使用 GCJ-02；东城区外围边界在地图运行时通过高德 `AMap.DistrictSearch` 获取并复用。  
> 学区边界仅用于购房与教育信息研究，不作为入学资格或官方划片依据；实际政策以东城区教委当年文件为准。

## 学区总览

| 学区 | 对应街道 | 已确认的主要边界 |
|---|---|---|
| 和平里学区 | 和平里街道 | 南界为用户给定折线；西、北、东三面沿东城区外围边界 |
| 安交学区 | 安定门街道、交道口街道 | 南界为地安门东大街—张自忠路；北接和平里，东接中轴分界，西沿区界 |
| 景东学区 | 景山街道、东华门街道 | 北接安交，南界为前门东大街一线，东接中轴分界，西沿区界 |
| 天永学区 | 天坛街道、永定门外街道 | 北、东界为珠市口东大街—崇文门外大街—天坛路—天坛东路；其余沿区界 |
| 北东学区 | 北新桥街道、东直门街道 | 西接中轴分界，南接北新桥南界；其余沿区界，并复用东直门西界 |
| 东朝建学区 | 东四、朝阳门、建国门等街道 | 北接北东，西接景东/中轴分界，南接建国门南界，东沿区界 |
| 东崇前学区 | 东花市街道、崇文门外街道、前门街道 | 北接景东、东朝建；南接天永、龙体；其他边界沿区界 |
| 龙体学区 | 龙潭街道、体育馆路街道 | 北界及东北段采用给定折线；西接天永；东、南沿区界 |

## 共用边界规则

- 学区间的共用边界只维护一套坐标，避免重叠或缝隙。
- 外围边界不手工拟合，统一从高德东城区行政区边界截取相应弧段。
- 南北主分界沿雍和宫大街—东四北大街—东四南大街—东单北大街—崇文门内大街，北至和平里南界，南至崇文门西大街交叉口。
- 地图中该主分界仅作为学区闭合的共享几何，不做醒目标签展示。

## 地图闭合关系

- 和平里：给定南界 + 区界北侧弧段。
- 安交：和平里南界西段 + 主分界北段 + 地安门东大街—张自忠路 + 西侧区界。
- 景东：安交南界 + 主分界中段 + 景东南界 + 西侧区界。
- 北东：和平里南界东段 + 东侧区界 + 东直门西界 + 北新桥南界 + 主分界北段。
- 东朝建：北新桥南界 + 东直门西界南段 + 东侧区界 + 建国门南界 + 主分界中段。
- 天永：给定北/东界 + 东城区南侧及西南侧外围边界。
- 龙体：给定北/东北界 + 东城区东南侧外围边界 + 与天永共用边界。
- 东崇前：景东南界和建国门南界组成北界；天永北界西段和龙体北界组成南界；东西两端沿区界闭合。

## 数据维护约定

1. 新坐标仍使用 `[经度, 纬度]`，保留 6 位小数。
2. 道路修订优先替换“共用边界”，不要分别修改两个相邻学区。
3. 学校点位与学区边界分文件维护；缺少地址时优先使用高德学校名称搜索。
4. 每次边界调整后检查：无自交、无重复覆盖、无缝隙、标签位于多边形内部。
